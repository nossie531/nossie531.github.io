Default トレイトでジェネリクス型の既定値を参照する方法について。

解決策

2026 年現在では、解決策 B がお勧めになる。ただし、将来的には解決策 A が不安定な機能なしでも使えるようになるか、なんらかの別の改善がされるだろう。一方、解決策 C は使いどころが難しい気がする。

失敗例

ジェネリクスの誤用

一見すると、この問題はジェネリクスを普通に使うだけでも解決できそうに思える。しかし、ジェネリクスはその単層化ごとに内部アイテムを作るわけではない。そのため、以下のコードはうまくいかない。 


use std::any::Any;

fn main() {
    assert_eq!(default::<i32>(), &0);
    assert_eq!(default::<bool>(), &false);
}

fn default<T>() -> &'static T
where
    T: Default + Any + Sync + Send,
{
    static VAL: T = Default::default();
    &VAL
}

解決策 A

不安定な機能

不安定な機能を使うと簡単にできる。

サンプル

以下では、定数の初期化に Default::default 関数を使っているため、まだ不安定な機能、const_default と const_trait_impl が必要になっている。 


#![feature(const_default)]
#![feature(const_trait_impl)]

fn main() {
    assert_eq!(&i32::DEFAULT, &0);
    assert_eq!(&bool::DEFAULT, &false);
}

trait ConstDefault {
    const DEFAULT: Self;
}

impl<T: const Default> ConstDefault for T {
    const DEFAULT: Self = T::default();
}

解決策 B

有名クレート

const-default クレートが使える。このクレートではトレイト Default の代わりに別のトレイト ConstDefault を用意している。そして、初期化はブランケット実装を使わず型ごとに行う方針をとっている (不安定な機能が不要)。そして、標準の型は予めそれぞれ実装、それ以外は derive マクロで関数 Default::default に処理を転送するようにしている。

なお、このクレートはかなり有名であり、それゆえこの問題に適している。なぜなら、たとえ一部でも Default トレイトの代わりを果たすトレイトを導入するには、それなりの知名度が求められる。無名のクレートがそうしたトレイトを乱立させるより、こうした有名クレートが一つあるほうが助かる。 


use const_default::ConstDefault;

fn main() {
    assert_eq!(&i32::DEFAULT, &0);
    assert_eq!(&bool::DEFAULT, &false);
}

解決策 C

動的キャッシュ

マップで型ごとの既定値をキャッシュする。

この方法には以下の欠点がある。

  • 動的なメモリ確保が必要になる。
  • 動作がほんの少しだけ遅い。

サンプル

以下では、ハッシュマップを使っている。 


use std::any::{Any, TypeId};
use std::collections::HashMap;
use std::hash::{BuildHasherDefault, DefaultHasher};
use std::sync::RwLock;

fn main() {
    assert_eq!(default::<i32>(), &0);
    assert_eq!(default::<bool>(), &false);
}

fn default<T>() -> &'static T
where
    T: Default + Any + Sync + Send,
{
    type HashBuilder = BuildHasherDefault<DefaultHasher>;
    type Map = HashMap<TypeId, Box<dyn Any + Sync + Send>, HashBuilder>;
    static MAP: RwLock<Map> = RwLock::new(HashMap::with_hasher(BuildHasherDefault::new()));

    let map = MAP.read().unwrap();
    if let Some(val) = map.get(&TypeId::of::<T>()) {
        let val = val.downcast_ref::<T>().unwrap();
        return unsafe { &*(val as *const _) };
    }

    drop(map);
    let mut map = MAP.write().unwrap();
    let bx = Box::new(T::default());
    let entry = map.entry(TypeId::of::<T>()).insert_entry(bx);
    let val = entry.get().downcast_ref::<T>().unwrap();
    unsafe { &*(val as *const _) }
}
