error[E0562]: `impl Trait` is not allowed in the type of variable bindings

パターン

パターン A

let 束縛

let 束縛の型に impl 抽象化を使用したパターン。

サンプル


fn main() {
    let x: impl std::fmt::Display = 1;
    println!("{x}");
}

解決策 1 - 不安定な機能

エラーメッセージにある通り、2026 年現在はまだナイトリー限定だが、
不安定な機能 impl_trait_in_bindings を有効化すると解決される。

解決策 2 - マクロ

マクロを使うと安定板でも対策できる。 


macro_rules! to_impl {
    ($x:expr, $t:ty) => {{
        fn f(x: $t) -> $t {x}
        f($x)
    }};
}

fn main() {
    let x = to_impl!(1, impl std::fmt::Display);
    println!("{x}");
}

解決策

キャストなどの場合、前のパターンと同様のマクロが使える。 


macro_rules! to_impl {
    ($x:expr, $t:ty) => {{
        fn f(x: $t) -> $t {x}
        f($x)
    }};
}

fn main() {
    let x = to_impl!(1, impl std::fmt::Display);
    println!("{x}");
}
